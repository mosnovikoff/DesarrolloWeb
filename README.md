# Calculadora Web – Actividad 3

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora web interactiva que permite realizar operaciones matemáticas básicas mediante una interfaz sencilla y funcional.

## Tecnologías utilizadas

- **HTML5:** estructura de la calculadora.
- **CSS3:** diseño visual, estilos y distribución de los elementos.
- **JavaScript:** lógica de las operaciones y funcionalidad de los botones.

## Funcionalidades

- Suma.
- Resta.
- Multiplicación.
- División.
- Operaciones con números decimales.
- Borrar todo el contenido de la pantalla.
- Eliminar el último dígito ingresado.
- Control de división para evitar dividir entre cero.

## Estructura del proyecto

- `index.html`: contiene la estructura de la calculadora.
- `style.css`: contiene los estilos y el diseño visual.
- `script.js`: contiene la lógica y las operaciones matemáticas.
- `README.md`: contiene la documentación del proyecto.
